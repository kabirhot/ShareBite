This folder holds the MySQL JDBC driver: mysql-connector-j-8.4.0.jar

run.bat downloads it automatically the first time if it is missing.
To get it by hand, download it from:
https://repo1.maven.org/maven2/com/mysql/mysql-connector-j/8.4.0/mysql-connector-j-8.4.0.jar
and put the .jar file in this folder.
